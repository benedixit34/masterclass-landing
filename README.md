# Masterclass Booking Platform

A responsive multi-step masterclass booking and payment platform built with HTML, JavaScript, and Tailwind CSS.

## Features

- **Multi-step registration form**
- **Country and phone number selection**
- **Dynamic masterclass and session selection**
- **Multiple ticket types and pricing**
- **Tool/skill selection**
- **Flutterwave payment integration**
- **Web3Forms booking submission**
- **Client-side form validation**

## Tech Stack

- **HTML5**
- **JavaScript**
- **Tailwind CSS**
- **Flutterwave**
- **Web3Forms**
